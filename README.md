# Cookbook

Collection of recipes, condensed from web sources into short, scannable
instructions for a busy kitchen.

Each recipe is one markdown file under `docs/src/`, with five sections:
Shopping, Prep, Cook, Notes, Citation. Pass no paths to `lint` or `fmt` and they
walk the whole tree - a shell glob will miss the nested folders.

## Adding or changing a recipe

`template.md` is both the skeleton and the house style guide. Copy it, delete
everything below the `DELETE FROM HERE DOWN` banner, and follow the
`## Conventions` block you just removed.

`recipe_tools.py` checks a recipe against those conventions and formats it the
same way the pre-commit hook does:

```sh
python recipe_tools.py lint        # every recipe; -w to include warnings
python recipe_tools.py fmt         # every recipe
```

Drop the file in the right folder and that is it. Courses are split by season

- `1_Entrees/2_Summer/`, `3_Desserts/0_Anytime/` and so on - and `0_WantToTry/`
    holds anything not yet cooked enough to file. The site nav is generated from
    the folder structure by the `navigation.md` files, and the recipe lists in
    `docs/src/index.md` are regenerated by:

```sh
python recipe_tools.py index
```

Both take their names from each recipe's H1, so a recipe is named in exactly one
place.

## Building the site

```sh
cd docs && mkdocs serve      # gh-deploy --force to publish
```
